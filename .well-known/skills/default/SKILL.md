# weightedstate

A package for weighted event prediction.

## Installation

```bash
pip install weightedstate
```

## API overview

### Weighted estimation

Estimate weighted state occupation probabilities.

- `weighted_aalen_johansen`: Calculate a weighted Aalen-Johansen estimate
